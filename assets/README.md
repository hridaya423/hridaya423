# The workbench

Original 3D illustrations, modeled and lit in Blender for this profile.
The glTF models and camera framing were inspected in Three.js before the final
Cycles renders.

- **Lexis:** an anodized terminal with a glass screen, key legends and machined ports.
- **Foundry:** an exploded ceramic command key over a metal switch assembly.
- **silk reel:** a circuit board with copper traces, plated vias and labeled components.
- **Strobe:** a stack of metal film frames with open perforations.

The final images use procedural surface finishes, conductor reflections, glass
refraction, studio softboxes, depth of field and rendered contact shadows. The
desktop banner places all four objects in one scene. The mobile banner gives
each object more room in a separate composition.

These are visual interpretations of the software, not product screenshots or
physical products. No third-party artwork or portfolio screenshots are used.
Typography is rasterized DIN Condensed, Arial, and Andale Mono; the images embed
no font software.

The six WebP files form a self-contained set, with no Three.js runtime on GitHub.
The mobile banner is selected on screens up to 600 pixels wide. Each project cover renders
at up to 400 pixels wide, allowing pairs on wider screens and a single column on
phones. The artwork uses fixed colors that work on both GitHub themes.

Image alternative text and the expandable project index preserve project
descriptions and destinations without the artwork.
